Lunara — Tableware E-Commerce Website
 
Crafted for every table.
 
Lunara is a tableware e-commerce concept I designed and built to explore clean, elegant UI for a lifestyle/home brand. 
The site walks through product categories, curated collections, and everyday shopping flows like browsing best-sellers and adding items to a cart.
 
What I Used
» HTML5
» CSS3
» Bootstrap 5
» Bootstrap Icons
 
What's on the Site
• Category-based browsing (Dinner Sets, Cutlery, Glassware, and more)
• A curated "Featured Collections" section
• Best-selling products with ratings and pricing
• A New Arrivals section
• A promotional/seasonal offer banner
• Fully responsive layout across devices

About This Project
 
I built Lunara as a UI/UX design exercise, focused on getting the visual hierarchy, spacing, and product presentation to feel premium and easy to shop.
There's no backend yet — it's a front-end static build, with cart functionality and mobile refinements planned as next steps.
